# Agent Workflow

`.agent/` contains files used to guide AI-assisted project work.

## Layout

- `PLAN.md` — long-term project plan;
- `PHASE-1-TODO.md` — active implementation checklist;
- `instructions/` — system and model-specific agent instructions;
- `skills/` — Pi skills and extensions.

Durable project knowledge belongs in `memory/`, not `.agent/`.

Use `/agent` for agent workflow files and `/memory` for project memory.
