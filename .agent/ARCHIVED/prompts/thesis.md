# Thesis Scope Prompt

Scope: `/thesis`

Write only under `thesis/`.

## Writing rules

- Keep thesis text formal, clear, and technically precise.
- Preserve thesis structure and terminology.
- Separate claims, design decisions, implementation details, and evaluation.
- Support externally verifiable claims with citations.
- Do not invent results, measurements, references, or system behavior.

## Project alignment

- Describe the implemented system, not speculative future architecture.
- Keep diagrams and text consistent with current architecture state.
- Record major architecture decisions in memory when thesis work depends on them.
